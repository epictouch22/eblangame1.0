# SPACE GTA в Eblangame

Добавлен отдельный режим **SPACE GTA** с оригинальной браузерной игрой из пользовательского файла `Space GTA.html`. Старый режим GTA не удалён, чтобы не потерять его механику.

## Запуск

1. Открой Eblangame, создай комнату и пригласи друзей.
2. Хост выбирает **SPACE GTA** в списке режимов. Для запуска все игроки нажимают **ГОТОВ**, затем хост — **НАЧАТЬ**.
3. Альтернативный запуск для хоста: команда `/gta` в комнатном чате.
4. Для выхода хост нажимает **В КОМНАТУ** над игрой. Все участники возвращаются в обычное лобби.
5. Старая GTA остаётся доступной хосту командой `/oldgta`.

## Онлайн

* До 10 участников одной комнаты Eblangame.
* Оригинальная игра открывается внутри Eblangame. Новый логин и дополнительная комната не нужны.
* Через Socket.IO сервер Eblangame передаются позиции, корабли, никнеймы, чат и сообщения совместного боя с боссами. Клиент остаётся ответственен за собственную симуляцию.
* Это **кооперативный режим**, а не полноценный серверно-авторитетный MMO/PvP: обычные NPC и индивидуальный игровой прогресс локальны.
* Игровые сохранения оригинального файла по-прежнему лежат в `localStorage` браузера (`sgta1`). Не очищай данные сайта, чтобы их не потерять.

## Технически

* `public/space-gta.html` — исходная Space GTA с небольшим адаптером окружения, который активен только при `?eblan=1`.
* `client/src/main.tsx` — отдельный iframe-экран и мост сообщений. Соединение Socket.IO принадлежит Eblangame, а не iframe.
* `server/src/index.ts` — ограниченный комнатой relay для `space_gta:presence`, `space_gta:event` (chat, bh, bk), списка пилотов и отключений. Проверяется членство в комнате, данные нормализуются, запросы ограничены по частоте.
* При сборке Vite содержимое `public/` автоматически копируется в `dist/`. Специальной маршрутизации в Express не требуется.

## Проверки после установки

* `npm install`
* `npm run build`
* `npm start`
* Создай комнату с ПК и телефоном, выбери SPACE GTA; проверь старт на обоих, корабли и чат, полёт и прицеливание, возвращение хостом и повторный запуск.
* Проверь, что `/oldgta` и Minecraft работают независимо, а выбранный режим не сменяется во время игры.

Примечание: серверный relay не хранит личные сохранения игры и не обеспечивает синхронизацию всех NPC/экономики. Для этих систем потребуется отдельная серверно-авторитетная переработка Space GTA.
